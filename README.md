✨ About The Project
This is a responsive E-Commerce Website developed using frontend technologies.
The project focuses on a clean user interface, product browsing, interactive shopping cart functionality, and a mobile-friendly experience.

🚀 Features
🏠 Modern Homepage with clean UI

🛍️ Product Cards for product browsing

🛒 Shopping Cart functionality

➕ Increase / Decrease Quantity

❌ Remove Products from cart

💰 Dynamic Cart Total

⭐ Customer Reviews section

📱 Responsive & Mobile-Friendly Design

🎨 Smooth Hover Effects & Animations

📱 Responsive Navigation
